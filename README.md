# Java Duplicate File Finder

This is a Java project I am currently working on. The program will let the user enter a folder path and will check the files inside that folder.

It will group files that have the same file size and show them as potential duplicates. This does not always mean the files are exactly the same because different files can have the same size.

## What the program will do

- Ask the user for a folder path
- Check if the folder exists
- Read the files in the folder
- Get the name, path and size of each file
- Group files that have the same size
- Show groups that contain two or more files
- Work out how much space could possibly be saved
- Handle errors such as an invalid folder or an empty folder

The first version will only check files in one folder. I may add subfolder scanning later.

## Why I am making it

I am making this project to improve my Java skills and get more practice with file handling, loops, methods, ArrayLists, HashMaps and error handling.
